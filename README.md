
# Student Registration System

## 📌 About the Project

The **Student Registration System** is a simple web-based application designed to register and manage student information. It allows users to enter student details through a registration form and display the registered students in a table.

This project was created using HTML, CSS, and JavaScript as a basic demonstration of web development and form handling.

## ✨ Features

- Register new students.
- Enter student's first name, middle name, and last name.
- Provide an email address.
- Select a course from the available courses.
- Select the student's year level.
- Enter the student's section.
- Display registered students in a table.
- Simple and user-friendly interface.
- Required field validation.

## 🛠️ Technologies Used

- **HTML5** – Structures the registration form and student table.
- **CSS3** – Styles the webpage and improves its appearance.
- **JavaScript** – Handles form submissions and student registration functionality.

## 📋 Student Information

The registration form collects the following information:

1. First Name
2. Middle Name
3. Last Name
4. Email Address
5. Course
6. Year Level
7. Section

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `index.html`, `styles.css`, and `script.js` are in the same directory.
4. Open `index.html` in your preferred web browser.
5. Fill out the student registration form.
6. Click the **Add Student** button to register a student.

## 🎯 Purpose of the Project

The purpose of this project is to practice and demonstrate basic front-end web development skills, including HTML form creation, CSS styling, JavaScript functionality, and displaying dynamic data using tables.
